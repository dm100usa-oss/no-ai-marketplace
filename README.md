# Заголовок первого экрана и блок под категориями. Итоговый архив

Этот архив содержит все изменения целиком и заменяет собой changes-01.
Распаковать в корень проекта, папка src ляжет поверх существующей.

## Что изменено

### 1. Заголовок первого экрана, обе версии

RU:
- «Международная платформа»
- «Для талантливых профессионалов, работающих без ИИ» + перенос строки + «и для бизнеса, которому нужен надежный результат»

EN:
- "An international platform"
- "For talented professionals creating without AI," + перенос строки + "and businesses seeking reliable results"

Перенос строки жесткий, задан в самом тексте. Вторая строка всегда начинается с «и для бизнеса» / "and businesses".

### 2. Размер третьей строки уменьшен

Телефон 1.15 стало 0.95, планшет 1.5 стало 1.25, большой экран 1.7 стало 1.4. Примерно на семнадцать процентов меньше. Лесенка размеров сверху вниз сохранена.

### 3. Блок под кнопками категорий

«Получайте целевых клиентов» заменено на «Привлекайте целевых клиентов». Английский вариант "Reach the right clients" оставлен без изменений.

## Файлы

- src/i18n/dictionaries/ru.ts
- src/i18n/dictionaries/en.ts
- src/app/[lang]/page.tsx
- src/app/[lang]/layout.tsx

В layout.tsx перенос строки убирается из названия вкладки браузера и из карточки для соцсетей, разделитель между строками изменен с запятой на точку.

## Проверка

Полная сборка npm run build, затем npm start и проверка обеих версий страницы. Ошибок нет.

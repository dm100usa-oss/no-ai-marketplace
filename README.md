# changes-09

Чинит сборку. Архив changes-08 лег на GitHub неполным: описание страницы
«Этапы создания работы» в types.ts попало, а сами тексты нет. Из-за этого
последний деплой на Vercel падал, и сайт жил на предыдущей сборке.

Ставить после changes-08. Файлы заменяют существующие, новых папок нет.

## Что внутри

**src/i18n/dictionaries/ru.ts**
- footer.workStages: подпись ссылки в подвале.
- workStages: полный текст страницы «Этапы создания работы»: вступление,
  девять разделов, восемь вопросов и ответов, блок с кнопками.
- profile.stagesTitle и profile.stagesHint: подписи блока этапов в профиле,
  их тоже не хватало.

**src/i18n/dictionaries/en.ts**
- То же самое на английском.

**src/i18n/types.ts**
- В блок workStages добавлены subtitle, faqTitle и faq.

**src/app/[lang]/work-stages/page.tsx**
- Своя верстка вместо общей ContentPage: подзаголовок, ссылки прямо в тексте,
  блок вопросов внизу.
- Две разметки для поисковиков и ИИ: FAQPage и HowTo, обе строятся из того же
  словаря, что и видимый текст, поэтому разойтись не могут.
- Ссылки внутри текста задаются метками вида [[method]] в словаре, адреса
  собраны в одном месте в начале файла.

**src/components/FAQ.tsx**
- Ответ теперь может содержать ссылку, а не только текст. На остальных
  страницах ничего не меняется.

## Проверено

npm run build проходит полностью, npm start, обе версии страницы открываются,
ссылки внутри текста работают, обе разметки в HTML присутствуют, буквы ё и
длинных тире нет.

## Что осталось незакрытым

Блока этапов в профиле по-прежнему нет. Анкета этапы собирает, они доходят до
админки и там останавливаются: submission-to-profile.ts их не переносит, а
ProfileView.tsx не показывает. Страница обещает то, чего посетитель пока не
увидит. Это следующая задача.

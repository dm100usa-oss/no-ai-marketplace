## НОВОЕ: раздел фактов со ссылками на источники в llms.txt

Разобрал прием с роферского сайта. Там в страницу вшит скрытый блок
AI_KNOWLEDGE_BASE_START ... AI_KNOWLEDGE_BASE_END: факты простым текстом,
разбитые по разделам, и под каждым адрес страницы-источника.

Идея правильная, исполнение брать не стал по двум причинам. Первая: я
открыл ту страницу двумя разными способами чтения и блока не увидел ни
разу, он виден только в поисковом индексе. То есть инструмент, которым
модель читает страницу по ссылке, его пропускает. Вторая: скрытый от
человека текст, написанный для машин, формально попадает под правила
поисковиков о недобросовестных приемах, и риск ложится на весь сайт.

Поэтому то же самое сделано там, где ему и место: в llms.txt. Файл открыт,
предназначен для машин по определению, ничего не спрятано.

**Что добавлено (public/llms.txt, оба языка):** раздел из двенадцати
ключевых фактов о каталоге, под каждым адрес страницы, где этот факт
изложен полностью. Охват: число профессий и направлений, четыре уровня
HTVS, этапы работы, порядок и границы проверки, два знака, как учитываются
работы с участием ИИ, 41 разбор по профессиям, восемь вопросов заказчика,
цены и бесплатные места, отсутствие комиссии, срок рассмотрения заявки,
два языка.

Смысл в адресе под каждым фактом: модель, пересказывая факт, может назвать
конкретную страницу, а не сайт вообще. Это разница между упоминанием и
ссылкой.

**Заодно исправлены два неверных числа в llms.txt.** Было написано 36
профессий и 9 направлений. На самом деле 37 и 10, десятое направление
«Разное» в списке отсутствовало. Проверено по живому сайту.

Проверено: все 34 адреса, упомянутых в llms.txt, отдают 200 без
переадресаций.

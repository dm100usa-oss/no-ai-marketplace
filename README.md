Что меняется

Заменены все иконки сайта на новые: значок вкладки в браузере, значок для
экрана айфона, значки для андроида и та иконка, которую Next.js
подставляет сам на служебных страницах.

Манифест не тронут: в присланном файле имя сайта было пустым и цвет белым,
а в нашем стоит No AI Directory и наш темно-синий. Менять на пустой смысла
нет.

Установка

Распаковать в корень проекта с заменой.

Важно про папку public: архив содержит папку public наравне с src, обе
кладутся в корень проекта.

Проверено

npm run build проходит
npm start, все иконки отдаются по своим адресам

После заливки значок в браузере может держаться старым: браузер хранит его
отдельно. Помогает открыть адрес сайта с /favicon.ico на конце и обновить
страницу, либо просто подождать.

# changes-07. Профиль появляется в каталоге сам

Ставить после changes-06. В архиве только то, что изменилось после него.
Содержимое папки changes-07 положить в корень проекта, файлы лягут поверх существующих.

## Что теперь работает

Вы одобряете заявку в админке, человек нажимает ссылку в письме, и профиль сам появляется в каталоге. Вручную переносить ничего не нужно. Работает для авторов, команд и компаний.

## Как решены сложные места

### Категория

В заявке категория написана словом («3D-художники»), каталогу нужна внутренняя пометка. Отдельный словарь не заводился: используются названия из уже существующих файлов категорий на обоих языках. Новая категория начинает работать сама, без правок. Непонятная категория останавливает публикацию и показывает предупреждение в админке.

### Адрес страницы

Собирается из имени, кириллица переводится в латиницу. При совпадении имен второй получает адрес с цифрой.

### Команды

Участники ищутся среди уже опубликованных авторов по имени. Найденные становятся ссылками, ненайденные остаются в списке без ссылки и в счет участников не идут. Контактное лицо всегда считается членом команды. Команда публикуется от двух живых профилей.

Участники ищутся заново при каждой пересборке, поэтому человек, создавший профиль позже, подтягивается в команду сам, переодобрять заявку не нужно.

### Ссылки

Раскладываются по площадкам автоматически: Etsy, Amazon, Behance, Dribbble, LinkedIn, Instagram, YouTube. Незнакомые попадают в общий список, ничего не теряется.

### Обновление страниц

Каталог, главная, категории, направления и карта сайта пересобираются сами при одобрении и при подтверждении почты.

## Новые файлы

- src/lib/category-lookup.ts — поиск категории по названию на любом из двух языков
- src/lib/slugify.ts — адрес страницы из имени, с переводом кириллицы
- src/lib/submission-to-profile.ts — превращение заявки в профиль
- src/lib/live-profiles.ts — каталог из файла проекта плюс одобренные заявки
- src/lib/refresh-catalog.ts — пересборка страниц после изменений

## Измененные файлы

- src/lib/localized-data.ts — чтение профилей из живого каталога
- src/app/sitemap.ts — карта сайта включает новые профили
- src/app/[lang]/page.tsx, directory, verified, categories, categories/[slug], directions/[slug], creators/[slug], teams/[slug], companies/[slug] — чтение живого каталога
- src/app/[lang]/confirm/page.tsx — пересборка после подтверждения почты
- src/app/api/admin/submissions/route.ts — пересборка после одобрения, проверка готовности заявки
- src/components/AdminClient.tsx — предупреждения по-русски до нажатия кнопки
- src/components/ProfileView.tsx, CreatorCard.tsx, ParticipantPageView.tsx — чтение живого каталога

## Проверка

Шесть пробных заявок прогнаны через механизм. Проверено: русская категория, несуществующая категория, совпадение имен, имена с дефисом, команда с двумя живыми профилями, команда без участников, компания.

Полная сборка npm run build, затем npm start и проверка страниц на обоих языках. Ошибок нет.

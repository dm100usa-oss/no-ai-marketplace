# changes-08. Отзыв можно оставить одними звездами

Ставить после changes-07. В архиве только то, что изменилось после него.
Содержимое папки changes-08 положить в корень проекта, файлы лягут поверх существующих.

## Что изменено

### Текст отзыва стал необязательным

Раньше форма не давала отправить отзыв без текста: требовалось написать не меньше десяти символов. Теперь достаточно поставить звезды.

Если человек все же начал писать, требуется хотя бы десять символов, чтобы не проходили случайные буквы. Проверка стоит и в форме, и на сервере.

### Подписи полей

RU: «Отзыв» стало «Отзыв (необязательно)», подсказка внутри поля «Расскажите о своем опыте» заменена на вопрос «Что вам понравилось на площадке?»

EN: "Review" стало "Review (optional)", подсказка "Tell us how it went" заменена на "What did you like about the platform?"

Вопрос вместо описания работает лучше: человек отвечает, а не сочиняет.

### Страница отзывов

Отзыв без текста больше не рисует пустой абзац. Показывается имя, звезды и дата.

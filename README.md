# Изменения: заголовок первого экрана и блок под категориями

## Что изменено

### 1. Заголовок первого экрана (обе версии)

Было:
- RU: «Международная платформа для талантливых профессионалов» / «создающих работы без использования искусственного интеллекта»
- EN: "An international platform for talented professionals" / "who create work without using artificial intelligence"

Стало:
- RU: «Международная платформа» / «Для талантливых профессионалов, работающих без ИИ» + новая строка + «и для бизнеса, которому нужен надежный результат»
- EN: "An international platform" / "For talented professionals creating without AI," + новая строка + "and businesses seeking reliable results"

Перенос строки жесткий, задан прямо в тексте. Вторая строка всегда начинается с «и для бизнеса» / "and businesses".

### 2. Блок под кнопками категорий

«Получайте целевых клиентов» заменено на «Привлекайте целевых клиентов». Английский вариант "Reach the right clients" оставлен без изменений, он уже передает этот смысл.

## Файлы

- src/i18n/dictionaries/ru.ts — новый текст заголовка, новый заголовок блока
- src/i18n/dictionaries/en.ts — новый текст заголовка
- src/app/[lang]/page.tsx — включено отображение переноса строки в подзаголовке
- src/app/[lang]/layout.tsx — перенос убирается из заголовка вкладки и карточек для соцсетей, разделитель между строками изменен с запятой на точку

## Проверка

Выполнена полная сборка npm run build, затем npm start и проверка обеих версий страницы. Ошибок нет.

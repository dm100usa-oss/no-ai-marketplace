# Заголовок первого экрана и блок под категориями

Архив содержит все изменения целиком и заменяет собой предыдущие.
Распаковать в корень проекта, папка src ляжет поверх существующей.

## Что изменено

### 1. Заголовок первого экрана

Русская версия:
- Международная платформа
- Для профессионалов работающих без ИИ
- и для бизнеса которому нужен
- предсказуемый и надежный результат

Английская версия:
- An international platform
- For professionals creating without AI
- and businesses seeking reliable results

Переносы строк жесткие, заданы прямо в тексте. Запятых внутри нет, разделение делают сами переносы. Слово «талантливых» убрано. Слова «предсказуемый и» есть только в русской версии.

### 2. Размер строки под заголовком

Было 1.15 на телефоне, 1.5 на планшете, 1.7 на большом экране.
Стало 1.15, 1.45 и 1.6. Размер одинаковый для обеих версий.

### 3. Блок под кнопками категорий

«Получайте целевых клиентов» заменено на «Привлекайте целевых клиентов». Английский вариант "Reach the right clients" оставлен без изменений.

## Файлы

- src/i18n/dictionaries/ru.ts
- src/i18n/dictionaries/en.ts
- src/app/[lang]/page.tsx
- src/app/[lang]/layout.tsx

В layout.tsx переносы строк убираются из названия вкладки браузера и из карточки для соцсетей, разделитель между строками изменен с запятой на точку.

## Проверка

Полная сборка npm run build, затем npm start и проверка обеих версий страницы. Ошибок нет.
